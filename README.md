# C Programming Coursework

C 프로그래밍 수업에서 작성한 과제와 실습 코드를 모아둔 저장소입니다. 과제는 랩별로 정리되어 있으며, 기본 문법부터 배열과 파일 입출력, 목록 관리 프로그램까지 연습했습니다.

A collection of assignments and exercises from a C programming course. Work is organized by lab and covers programming fundamentals, arrays, file I/O, and list management programs.

## Labs | 과제 목록

| **Lab 1 — C 기초** | 반복문과 별 출력 패턴, 배열을 이용한 점호 인원 합계·비율 계산 등 기초 콘솔 실습<br>Loops, star patterns, and array-based attendance and percentage calculation

| **Lab 2 — 과목 목록 관리** | 과목 목록 조회, 추가, 수정, 신청, 저장 실습<br>View, add, modify, apply for, and save course entries

| **Lab 3 — 채널 관리** | 채널 목록 조회, 통계, 무작위 선택, 검색, 수정, 삭제 및 보고서 저장<br>List channels, view statistics, pick randomly, search, edit, delete, and save a report

| **Lab 4 — 옷장 관리 시스템** | 옷장 조회, 색상·이름 검색, 옷 추가·수정·삭제, 변경 내용 저장<br>View and search clothing by color or name; add, edit, delete, and save items
